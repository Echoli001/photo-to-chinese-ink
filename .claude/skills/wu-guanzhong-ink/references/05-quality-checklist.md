## 来源二：出图后九维评分 `post_generation_gate`（v17 原文，逐字）

来自 `references/07-generation-protocol-yaml.md` 第 483-491 行。这是
**看到实际生成图片之后**才能打分的九个维度，总分 45（每维 0-5 分），
其中 5 个维度设了"关键最低分"（critical_minimums），任一未达标即视为
不合格，不能靠其他维度高分拉平均分掩盖。

```yaml
post_generation_gate:
  score_dimensions: [recognition, abstraction, line_rhythm, point_line_plane_routing, ink_material_authenticity, material_language, color_fit, composition, originality]
  minimum_total: 33/45
  critical_minimums:
    line_rhythm: 4/5
    point_line_plane_routing: 4/5
    ink_material_authenticity: 4/5
    material_language: 4/5
    originality: 4/5
```

九个维度的逐维打分标准来自 v17 §8.2「九项评分与通过线」（第
1777-1793 行，与 `score_dimensions` 顺序一一对应），原文逐字如下（每项
0-5 分）：

| 序号 | `score_dimensions` 标识符 | 中文维度名（v17 原文） | 通过要求（v17 原文） |
| --- | --- | --- | --- |
| 1 | `recognition` | 源图辨识与独有特征 | 3-4 分；过低为丢失信息，5 分通常意味着过于写实 |
| 2 | `abstraction` | 抽象提炼 | ≥3 分；必须发生取舍、破形或重组之一 |
| 3 | `line_rhythm` | 线条韵律与笔性 | ≥4 分（关键维度）；非周期、分层、有休止 |
| 4 | `point_line_plane_routing` | 点线面路由正确性 | ≥4 分（关键维度）；主载体没有被错误语言替代 |
| 5 | `ink_material_authenticity` | 生宣笔墨材质真实性 | ≥4 分（关键维度）；浓淡与干湿独立，湿墨有沁化/沉积/回流，干墨有飞白/裂变，且无统一水彩薄洗 |
| 6 | `material_language` | 墨色与混合媒介语言 | ≥4 分（关键维度）；浓枯湿、透明与不透明色层有明确主次，材质服务结构 |
| 7 | `color_fit` | 配色适配与多样性 | ≥3 分；保留色彩记忆但非机械复制 |
| 8 | `composition` | 画面整体与留白 | ≥3 分；密、疏、重、轻关系成立 |
| 9 | `originality` | 原创性与非复刻 | ≥4 分（关键维度）；无参考作品构图复刻、签名或真迹暗示 |

补充规则（v17 原文，第 1793 行）：**总分至少 33/45**，且线条韵律／点线
面路由／生宣笔墨材质真实性／墨色与混合媒介语言／原创性任一项不得低于
4 分。**出现水彩化，即使总分达标也一票否决。** 未通过时只调整导致失败
的变量，不同时改构图、比例、配色和抽象度（§8.3 第二轮迭代原则，第
1795-1801 行，同样适用于未来的人工出图评审流程）。

### 纸与墨材质基础

- [ ] 去掉纸纹和彩点后，黑白结构仍成立。
- [ ] 已明确使用高吸水性的生宣逻辑；纸纹只在墨水作用处显现，没有全画面统一纸噪点。
- [ ] 已根据用户要求与源图冷暖明确选择纸色并写出理由；没有把"生宣"自动等同于米黄、旧纸或仿古纹理。
- [ ] 高调、白墙、雪景、花卉或清澈天空题材已优先评估洁白／冷白／中性白生宣；没有被统一暖纸染色。
- [ ] 夕阳、秋色与暖光由墨彩、矿物色或刮色承担，纸面自身没有替代环境色。
- [ ] 去掉笔墨和彩色后，纸面保持安静，不像一张高对比复古纸纹素材。
- [ ] 墨的浓度与含水量分别设定；全画至少包含浓湿、淡湿、浓干或焦干、重墨半干四种组合。
- [ ] 每个主要墨块至少含两种墨态，最大的两个墨块至少含三种；没有单一透明度的灰黑填充。
- [ ] 湿墨可见不等宽沁化、墨核、沉积边、回流或墨水相撞中的至少三项，不是统一半径的模糊柔边。
- [ ] 干墨可见飞白、枯裂、侧锋摩擦或笔毫分叉中的至少两项，不是数字颗粒蒙版。
- [ ] 白墙、雪、水光与雾的亮部主要由留纸形成，不依赖白色颜料补画。
- [ ] 去掉彩色后，焦、浓、重、淡、清的黑灰白墨阶仍独立成立；没有滑向透明水彩明暗。

### 缩略图可读性与线条基础

- [ ] 5% 缩略图下能辨认主势和主要黑白块。
- [ ] 至少保留两个来自输入图的独有特征。
- [ ] 线条具有方向、层级与疏密变化，不是随机乱线。
- [ ] 没有逐条描摹重复轮廓；至少一半重复结构已被删除、合并、断开或转成留白。
- [ ] 已分别设定宏观拓扑保留率与微观边缘对应上限；没有用"保留信息"作为逐线临摹的理由。
- [ ] 对摄影性强线源图，输出第一眼是线群韵律、第二眼才辨认原景；纸白或极淡底场仍是主要平面。
- [ ] 至少存在一处疏密突变和一处可控意外，画面节奏不是稳定周期。

### 点线面语言与墨符号系统

- [ ] 已根据输入形态明确点、线、面的表达权重，并指定一个主导语言。
- [ ] 墨点、墨线、墨面均承担明确结构职责，墨没有退化为对象描边、灰度填充或照片滤镜。
- [ ] 约 10%-25% 的墨符号具有源图派生的形式自主性，可跨形、切面或在留白中停顿；没有无来源随机乱线。
- [ ] 主要墨面内部同时出现湿润泼入／积墨与渴笔扫擦／飞白，干湿燥润不是被机械分配给不同对象。
- [ ] 主要墨线至少发生一次浓淡、干湿、顿挫、断续或回弹变化；没有从头到尾同宽同黑。
- [ ] 黑灰白骨架在加色前已经成立；彩色与墨发生了 1-3 个并置、切割、穿插或压叠事件，而不是在黑线内填色。
- [ ] 高饱和彩色可以作为点、短线或自由色块，但去色后画面的重心、方向、疏密和留白仍完整。
- [ ] 复杂性来自枝干、网格或道路时，没有用大片墨团代替应由线表现的结构。
- [ ] 复杂性来自叶、灯、窗或碎石时，已经转化为有聚散变化的点，而不是逐个描绘或全部涂成面。
- [ ] 对森林等线性题材，线权重不低于 45%，施墨面覆盖未超过约 30%。

### 植物题材

- [ ] 对藤蔓、垂花和纠缠植物，第一眼先读到起伏跌宕的线性生命力，第二眼才辨认植物；不是柔美平滑的植物插画。
- [ ] 植物线群同时存在黑色骨线、偏移的灰色回弹线和游丝逸出线；灰线没有紧贴黑线形成机械双轮廓。
- [ ] 植物密度以"结—放—再结"组织：至少一处密结后跨越明显空场，并出现急转、回挑或逆重力线。
- [ ] 墨点和彩点落在交叉、转折、线端和反拍位置，存在附着点与悬浮点；没有沿枝条等距装饰。
- [ ] 已依据源图选择直立林冠、游园散点、林中层叠、满幅生长场或果实节点树之一，没有沿用上一张植物图的路由。
- [ ] 已保留源图的主生长轴、承重交点、密度区和主要纸白拓扑；没有只保留"像植物"的通用枝杈。
- [ ] 真连接、叠交、近失、悬浮四类关系至少混合三类；所有交叉没有被画成植物学式真实关节。
- [ ] 黑骨线、灰关系线与游丝空气线的粗细、含水和结构职责清楚；不是全画同宽同黑的乱线网。
- [ ] 彩点混用湿点、枯点、叶片楔形、三角、短划、小色面或残缺果圆，并同时存在附着与悬浮；没有"一叶一点"或全用同一圆点。
- [ ] 直立林冠保留冠下大白场；满幅生长场则以密度波和微型孔隙呼吸，没有机械套用大留白。
- [ ] 果实节点树中的果点大小、圆缺和聚散不一，枝线可穿、切或掩其边缘；没有变成整齐的圆果图案。
- [ ] 植物照片已填写形态卡，并依据主几何、主干可见度、冠层密度、方向场和白场结构选路由；没有只凭物种名称决定画法。
- [ ] 已删除约 45%-75% 可逐个对应的叶、花、果和末梢，保留的是主势、承重点、密度区和色彩记忆，不是照片换笔触。
- [ ] 前景主干以焦浓半干、提按顿挫和飞白为主，背景枝以淡湿灰墨退让；没有全画同一种水量和柔边。
- [ ] 焦、浓、中、淡灰以并置对比成立，没有用细腻连续渐变塑造写实立体感。
- [ ] 彩点无写实明暗与完整外轮廓；黑点和彩点混杂、遮压，并保留少量游离点和纸白间隙。
- [ ] 若使用明黄、玫红、艳绿、浅青，只选择与源图相符的 2-4 个色轴；没有把固定四色套到每张植物照片。
- [ ] 老树、花枝、密花、果树、藤蔓、竹林、密林、草芦、水生植物和风动枝叶的点线面比例遵循各自路由，而非统一模板。

### 都市题材

- [ ] 都市全景第一眼读成深、中、浅墨色体积的现代平面构成，第二眼才辨认建筑群；不是逐栋完成的建筑插画。
- [ ] 都市建筑已归并为约 7-16 个不等量体积组，每组可吸收 3-12 栋建筑；单栋可辨比例约 15%-30%，窗格写实比例不高于约 18%。
- [ ] 都市墨色至少具有浓墨核、中墨主体、淡墨呼吸和纸白/彩色间隙四种角色，深浅没有机械地对应固定远近。
- [ ] 天际线形成 4-7 级高低节奏和 1-3 个离群高点，包含骤降、停顿、反峰或低位收束，不是等距柱状图。
- [ ] 若都市构图取消统一透视，至少使用叠压、浓淡台阶、透明度、边缘清晰度、间隙宽度、尺度跳变中的三项建立空间。
- [ ] 都市建筑之间存在覆盖、咬合、共边、裁切或负形通道；没有"一栋楼一个矩形"和满画面重复窗格。

### 平面空间构成（俯瞰/阵列/密铺类题材）

- [ ] 鸟瞰、俯瞰、田地阵列、渔港船群、村镇屋顶或水岸碎片题材已填写"平面空间构成卡"；不是从题材名直接跳到水墨效果。
- [ ] 已移除或压低单一灭点与汇聚透视线；没有依赖近大远小、写实光影或传统山水层叠推远制造纵深。
- [ ] 已选择阵列重复、编织穿插、块点碎片化或满铺密构图中的一个主母型；次母型最多一个，且说明其结构职责。
- [ ] 已从疏密变化、墨阶台阶、单元颗粒度、透叠、边缘清晰度、纸白缝宽和方向冲突中选择至少三项重建层级。
- [ ] 阵列重复中的单元在方向、宽高、墨阶、间隙或间距上存在微扰；约 15%-30% 单元发生重叠、残缺或出框，没有机械网格复制。
- [ ] 满铺密构图包含密度波、1-3 条呼吸通道和 1-2 个安静区；高密度不等于无差别堵满画面。
- [ ] 平涂色没有渐变和体积塑造，但允许生宣上的湿核、颜料沉积与局部毛边；没有滑向数字硬边色块或透明水彩薄洗。
- [ ] 已选择 0-3 级抽象等级，并保留该级要求的识别锚点以及源图的主方向、视觉重量、密度地图和色彩记忆。
- [ ] 青苗田以短竖、绿点或小楔形成密度带；渔港以短舟、楔形和黑白胶囊形成方向群；二者没有被逐株、逐船描绘。
- [ ] 村镇屋顶已归并为斜墨面群，道路、院落或水巷转成纸白裂隙；梯田或水岸则分别以曲折线组或斜墨块、灰带和断水线建立拓扑。

### 江南水乡题材

- [ ] 江南水乡题材的屋顶由焦墨、飞白和湿边共同构成，不是轮廓线加统一灰填充；相邻屋顶已发生合并。
- [ ] 江南屋顶以湿墨主体生成形体：至少约 45% 边界圆融、毛化或晕开；干墨锐边只用于少数屋脊与挑檐。
- [ ] 湿墨屋顶内部有不少于三层浓淡、墨核、扩散或回流，不是硬黑块外加数字模糊光圈。
- [ ] 相邻 2-7 片屋顶已被合成整体浓淡墨团：第一眼读成墨块，第二眼才读成屋群；具象屋檐只剩 1-3 段不连续提示。
- [ ] 屋顶墨团同时含浓墨核、中墨主体和淡墨呼吸层；纯黑只作约 8%-15% 的骨点，不存在"全部浓黑"或"全部淡灰"。
- [ ] 江南白墙主要作为纸白负形成立，远山、水色和季节树木没有抢走黑白建筑节奏。
- [ ] 江南或自然水景至少使用两类非周期水线，并同时存在密线、断线和安静水面；没有平涂水色或精确镜像。
- [ ] 屋檐、灰墙或倒影已转化为角度、透明度和边缘不同的倒斜墨块，而不是机械排列的相同梯形。
- [ ] 已选择墨主导、油彩主导或均衡混合之一；透明墨层与不透明/刮擦彩层有明确主次，没有全画面同质水彩或厚涂。

### 收尾：破局、配色、原创性、交付

- [ ] 画面保留 3-5 个语义锚点，处于具象与半抽象之间；破局线和彩点来自源图节点且确实打破了规则构图。
- [ ] 配色由本张源图重新路由，没有无理由复用上一张图的黑白底与同组三原色。
- [ ] 已明确这次使用的 1-3 个技法模块，以及拒绝使用的错误技法。
- [ ] 彩色只承担节奏和情感激活，没有淹没黑白结构。
- [ ] 留白是主动构图，不是生成失败或内容缺失。
- [ ] 装饰元素能追溯到输入对象。
- [ ] 与任何单一参考作品不存在明显的整体构图复刻。
- [ ] 没有签名、印章、题款或真迹暗示。
- [ ] 交付尺寸的安全区、裁切和小尺寸识别性通过检查。

## 编译期可检查的二元否决项（compiler.py 会自动拦截）
