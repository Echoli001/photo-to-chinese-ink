## 6.1 硬性禁止

- 不复刻任何一件已知作品的整体构图、主体位置、线网路径和色点分布。
- 不生成或仿造吴冠中的签名、题款、印章、作品编号或鉴定信息。
- 不使用"吴冠中真迹""原作""官方授权"等误导性描述。
- 不把《双燕》《狮子林》《逍遥游》等标志性作品的独特结构直接作为模板。
- 不在公开 GitHub 仓库中打包、再发布画册扫描页或受保护的作品图像；参考资料
  只用于内部研究，公开仓库应存放语法、元数据、测试方法和自有/获授权示例。
- 不把用户上传照片的内容替换成吴冠中作品中的固定桥、白墙、燕子、江南村落
  等题材。

## 6.2 原创生成要求

每次输出必须同时满足：

1. **内容来源于用户图片**：至少保留 2 个输入图片独有的语义或拓扑特征。
2. **构图重新决策**：根据输入的方向、负空间和主体关系选择构图母型，而不是
   匹配某件原作。
3. **形式重组可解释**：能够说明哪些物体被转化成主形块、势线、墨点和彩点。
4. **色彩重新映射**：从输入色彩或交付场景生成新的受限色域，不复制某件参考
   作品的配色位置。
5. **不含身份伪装**：不出现艺术家签名、印章、仿制年份或虚构出处。

## 6.3 相似度检查

建议在 Skill 中加入三层自动检查：

1. **近重复检测**：使用 pHash/dHash 排除与参考图近似的裁切、缩放或色彩变体。
2. **语义相似检测**：使用 CLIP 或 DINOv2 对输出与参考库取 Top-K；高相似样本
   进入人工复核，而不是用单一固定阈值直接判定。
3. **构图特征检测**：比较主体框、主要黑块、边缘图和色点热图，防止语义不同
   但构图过近。

人工复核重点：主体位置、最大黑块轮廓、主势线、负空间形状、色点簇位置是否
与某一原作高度重合。

## 6.4 公开发布建议

- Skill 的公开说明应定位为"基于二十世纪中国现代水墨形式主义的研究性图像
  转换"，并清楚注明非官方、非艺术家基金会或博物馆授权产品。
- 如果名称中保留"吴冠中"，使用"风格研究 / visual grammar / inspired
  transformation"等限定语，不暗示作品真伪或官方关联。
- README 中说明：用户必须拥有上传图片的处理权；输出不得用于伪造、虚假鉴定
  或冒充艺术家作品。
- 商业化、模型训练集发布、作品图像再分发及特定司法辖区的权利问题，应另行
  进行专业法律审查。

## 与主 YAML `originality:` 字段的对应关系

| 主 YAML 字段 | 对应本文件内容 |
| --- | --- |
| `copy_reference_composition: forbidden` | 6.1 第 1 条（不复刻整体构图/主体位置/线网路径/色点分布） |
| `artist_signature_or_seal: forbidden` | 6.1 第 2 条（不生成或仿造签名、题款、印章、鉴定信息） |
| `preserve_user_subject: required` | 6.1 第 6 条 + 6.2 第 1 条（不替换用户照片主体，至少保留 2 个独有特征） |
| `similarity_review: [perceptual_hash, semantic_top_k, composition_map]` | 6.3 三层检查（pHash/dHash → CLIP/DINOv2 Top-K → 构图特征检测） |

`copy_reference_composition`/`artist_signature_or_seal`/`preserve_user_subject`
三个布尔字段可以在编译期做文本层面的否决检查（见
`references/05-quality-checklist.md` 的"编译期可检查的二元否决项"一节）。
`similarity_review` 的三层检测需要出图后对图像做处理，当前 MVP（仅出文字
prompt，不调用生图 API）阶段无法自动执行，留待后续图生成阶段实现。
