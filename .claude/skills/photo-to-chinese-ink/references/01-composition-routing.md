## 一、五种基础构图母型（对应 `composition_mode` 的 6 个枚举值）

`composition_mode.choose_from` 六项中，前五项直接对应 v17 §2.1-2.5 的
五种构图母型；第六项 `urban_grid_variation`（都市网格变奏）只在 §2.6
构图选择器的文字里作为都市夜景的分支出现，没有独立小节，见下方"都市
网格变奏"条目。

### 1. `jiangnan_geometry`（江南几何型，v17 §2.1，第 125-131 行）

- 大面积白墙或水面占画面约 **45%-70%**。
- 黑瓦、门窗、桥洞以短横、竖块和弧线形成节奏。
- 建筑不作为风景中的小配角，而是画面的几何主体。
- 空间可以压平，前后建筑允许互相叠压，透视不必严格统一。
- **适用**：住宅、街景、村落、庭院、桥梁。

### 2. `monumental_void`（巨碑留白型，v17 §2.2，第 133-138 行）

- 单一树、山峰、人物或建筑作为竖向/斜向锚点。
- 留白建议为 **55%-75%**，主体不必居中。
- 用少数浓墨块锁定视觉重量，再以淡墨轮廓和垂直渗化建立山体或雾气。
- 参考结构（v17 原文举《北国山色》为例）："高树为主轴、山体为薄层、
  人物和屋舍为微小尺度标记"。

### 3. `panoramic_flow`（横卷流动型，v17 §2.3，第 140-145 行）

- 采用宽幅横向构图，主势贯穿左右。
- 河岸、道路、山脊或建筑带形成连续曲线；局部黑块承担停顿。
- 不强调单一中央焦点，而强调观看过程和节奏展开。
- **适用**：电脑屏保、横向墙纸、长幅装饰画。

### 4. `immersive_network`（密网沉浸型，v17 §2.4，第 147-152 行）

- 线条、墨点、灰痕覆盖大部分画面，弱化传统远景和俯视空间。
- 观者像进入环境内部，而不是从远处观看全景。
- 必须存在粗细、疏密、方向和层级差异，**不能成为等密度噪声**。
- 参考结构（v17 原文举《逍遥游》为例）：交错线网、墨点和小彩点。

### 5. `urban_ink_volume`（都市墨色体积型，v17 §2.5，第 154-161 行）

- 将城市先看作高低、宽窄、浓淡不同的**墨色体积群**，而不是许多需要
  逐栋说明的建筑。
- 相邻 **3-12 栋**建筑可合并为一个体积；不同体积通过叠压、嵌合、
  错位、裁切和留缝构成"林林总总、错落有致"的平面秩序。
- 透视不是必选项。可采用压平正面、分层叠置、多视点拼接或压缩景深，
  让空间由墨色浓淡、透明度、遮挡和边缘清晰度成立。
- 天际线应形成**不等节拍**：突高、密集、骤降、停顿、再抬升；避免
  平均锯齿和均匀柱状图。
- 浓墨块压重，中墨块连接，淡墨块退让，纸白或底色缝隙提供呼吸；线与
  点只负责少量接缝、窗灯和破局。

### 6. `urban_grid_variation`（都市网格变奏，v17 §2.5 末句 + §2.6，第 161、171 行）

- 都市夜景仍可启用网格变奏：横竖结构线与灯点增强，但**不得重新退化
  为逐栋线描**。
- 触发条件（见下方选择器）：都市夜景主要由道路、窗灯和结构线发光。

## 二、构图选择器（v17 §2.6 原文逐字，第 163-174 行）

```text
若输入以白墙/建筑为主 -> 江南几何型
若有单一高树、人物、山峰或塔 -> 巨碑留白型
若地平线、河岸或山脊横向延展 -> 横卷流动型
若枝叶、森林、岩石或人群形成复杂网络 -> 密网沉浸型
若高楼、街区、建筑群以体积与天际线为主 -> 都市墨色体积型
若都市夜景主要由道路、窗灯和结构线发光 -> 都市网格变奏
```

**禁止**不看输入内容而随机套用桥、白墙、燕子、彩点等"吴冠中符号"
（v17 原文，第 174 行）——即 `composition_mode.derive_from_input: true`
在 YAML 里对应的硬性要求，`router.py` 选路时必须以诊断卡内容为唯一
依据，不能因为"想要更像吴冠中"而绕过诊断结果直接选某个模式。

## 三、技法模块选择器（v17 §2.7 原文逐字，第 176-198 行）

观察源图后**只选择 1-3 个**最匹配的技法模块；不能为了"风格明显"把
所有模块一起叠加。

| 源图的主要信息 | 首选技法 | 可组合技法 | 不应强加 |
| --- | --- | --- | --- |
| 已有高质量线网、折线或枝网 | 线网保留＋笔性翻译 | 疏密校准、少量墨点重音 | 大幅删线、巨碑留白、大块云雾 |
| 摄影中已有强烈重复走势，如梯田、浪、水纹 | 主势保留＋线群重谱 | 断裂、跨形连接、黑点重音、纸白负形 | 一线一边描摹、连续填色、写实水彩明暗 |
| 细长骨架附着大量小单元 | 主线骨架 | 点簇节拍、局部淡墨连接 | 用软色块取代纹理 |
| 白墙、雪地或几何空面 | 负形平面 | 断续轮廓、少量彩点 | 填满白面、平均加色 |
| 山体、夜色、浓荫等连续重量 | 浓淡墨面 | 山脊势线、局部破面 | 过多游丝线削弱重量 |
| 花、灯、人群等离散密集元素 | 不等量点簇 | 细线串联、少量底面 | 逐个描绘或等距撒点 |
| 已有完整抽象色场 | 色场保留＋纸性转换 | 墨线叠置、局部冷暖偏移 | 新造大留白、改写色场位置 |
| 单一强轮廓主体 | 巨碑式取势 | 留白、少量浓墨 | 密网覆盖主体 |

组合输出必须写成（v17 原文格式，compiler.py 拼装 prompt 时可直接
沿用这个结构做内部推理草稿，不必出现在最终 prompt 文本里）：

```text
Technique recipe = [主技法] + [可选辅技法 1] + [可选辅技法 2]
Reason = [这些技法分别对应源图中的什么信息]
Preserve = [不可丢失的构图、密度、方向和色彩关系]
Reject = [本图不适合使用的技法]
```

## 四、`flat_spatial_composition_route`（高角度压平，v17 §3.12A）

### 4.1 定位：不是 `composition_mode` 的第七个选项，是条件叠加层

`flat_spatial_composition_route.not_global_default: true`——这是一条
**条件触发的空间构成规则**，不是与六种 `composition_mode` 并列的选项，
而是在满足触发条件时叠加/替代默认透视处理方式的一层规则。v17 原文：
"本模块适用于鸟瞰、俯瞰、渔港、船群、青苗田、农田阵列、村镇屋顶、
滨水碎片、抽象墨块风景等输入。它不是所有题材的默认空间法；仅当源图
的俯瞰关系、重复单元或面群组织比写实纵深更重要时启用。"（第 556 行）

触发条件与 YAML 一致：`when: high_angle_or_aerial_view_or_repeated_
surface_units_are_primary`。

### 4.2 空间先压平，再重新分层（v17 第 558-565 行）

- **视点**：采用高角度、鸟瞰或近俯视；可以保留源图的总体方位和邻接
  关系，但取消单一消失点与透视线汇聚。
- **压平**：三维景物先投射为二维单元图，再以叠压、疏密、墨阶、颗粒
  尺度和纸白间隙重新组织。现实物理空间服从宣纸平面构成。
- **层级**：不依赖近大远小、写实光影或空气透视。浓淡首先决定构图
  重量，不机械对应前后；单元大小只作为节拍与层级粒度，不作为比例
  透视。
- **深度替代器**：每张图至少选择三项——密度突变、墨阶台阶、单元
  粒度差、叠压／透叠、边缘清晰度差、纸白通道宽度、方向冲突（对应
  YAML `depth_substitutes.choose_from`）。
- **禁止误用**：不能为了"压平"把所有单元做成同尺寸贴纸，也不能把
  鸟瞰图机械转换成整齐信息图。

`flat_spatial_composition_card` 的完整 YAML 字段已在
`07-generation-protocol-yaml.md`（第 174-186 行）逐字保留，此处不
重复。

### 4.3 四种构图骨架（对应 YAML `patterns`，v17 第 584-598 行）

1. **阵列重复 `array_repeat`**——将船、苗、屋顶、田块、礁石或人群压缩
   成同族符号，沿隐性网格、曲线带或斜向场重复。单元必须在方向、
   长宽、墨色、缺口和间距上发生微扰；约 **15%-30%** 单元可残缺、
   重叠或越出画框。阵列应向四周延展，形成画外继续生长的感觉。
2. **编织穿插 `interweave`**——以长短线、岸线、道路、枝网、船桅或
   田埂建立骨架；不同对象可以互穿、透叠和共边，弱化单体边界。至少
   包含一次主线跨越多个单元、一次断线后重现和一次方向反拍。
3. **块—点碎片 `block_point_fragment`**——把现实拆成浓墨块、中淡灰
   块、平涂色块、短线、墨点与纸白裂隙，再依重量与节奏重组。符号可
   偏离真实边界，但必须来自源图的面群、航向、道路、田块或岸线关系。
4. **满铺密构图 `dense_fill`**——让元素高密度覆盖画面并越出边界，
   但内部保留多尺度纸白缝隙、局部停顿和密度波。禁止全幅同密度；
   至少有一处密集结、一条呼吸通道和一个相对安静区。

**每张图只选择一种主骨架，最多叠加一种辅助骨架**。四种模式全部平均
使用会失去判断力（v17 原文，第 598 行）。

### 4.5 平面图形语言（v17 第 611-617 行，补充 YAML `graphic_language` 的叙述）

- **符号化**：每类对象只保留 1-3 个核心识别特征。例如船保留长短
  比例和航向，苗保留竖向萌发，屋顶保留倾斜与聚合，田埂保留回旋线势。
- **色彩**：使用平涂色点、短块或综合色带，不通过渐变和光影塑造
  体积。"平涂"不等于数字硬边或枯干丙烯；可保留湿笔色核、颜料沉积
  和局部生宣毛边，但单个色块内部不建立写实明暗。
- **对比驱动**：每张图至少选择两组主对比——大墨面／细碎墨点、
  黑色骨架／高饱和彩色、规整阵列／自由曲线、密集集群／纸白缝隙。
- **边缘**：轮廓可断续、共边、被覆盖或不闭合；后方单元允许从前方
  缝隙透出。硬边、湿边和消失边必须混用，不能全画统一剪纸轮廓。
- **色彩面积**：高饱和彩色集中于少数节奏区，不平均涂遍所有单元；
  去色后黑灰白构成仍须成立。

### 4.6 抽象连续滑动（对应 YAML `abstraction_continuum`，v17 第 619-630 行）

同一源图可以沿四级滑动，而不是在"写实／抽象"之间跳变：

| 等级 | 保留内容 | 删除与重组 | 观看顺序 |
| --- | --- | --- | --- |
| **0 符号化景物** | 5-8个识别锚点、总体邻接与方向 | 删除微观纹理，压平透视 | 先辨题材，再看形式 |
| **1 平面化风景** | 3-5个锚点、主要密度带和色忆 | 单体合并，透视减弱，点线面重谱 | 题材与形式同时可读 |
| **2 半抽象构成** | 2-3个锚点、黑白重心和总势 | 大量边界错位、碎片化和跨形 | 先看构成，再辨景物 |
| **3 点块抽象** | 1个锚点或仅保留源图拓扑 | 对象身份基本剥离，只留密度、方向和色彩记忆 | 先读点线面，景物只作回声 |

级别提高时，锚点与字面边界逐步减少，但**源图的主方向、重心、密度图
和色彩记忆不能同时消失**，否则不是抽象滑动，而是换题重画（v17 原文，
第 630 行）。这条规则与 `quality_score` 诊断卡的 `abstraction_level`
字段直接对应。

### 4.7 统一负面提示（v17 原文逐字，第 632-641 行）

```text
Avoid one-point perspective, converging vanishing lines, realistic near-large far-small
scaling, atmospheric depth, modeled light and shadow, gradient volume rendering, complete
closed object contours, mechanical perfect grids, identical repeated units, traditional
layered-mountain recession, architectural or cartographic illustration, smooth digital
color gradients, random abstraction without source topology, fully blocked dense fill,
text, logos, signatures, seals and watermarks.
```

这段负面提示只在 `flat_spatial_composition_route` 被激活时追加到
最终 prompt；未触发该路由时不应出现（避免与其他构图模式的负面提示
冲突，例如巨碑留白型本就需要纵深感，不适用"avoid atmospheric depth"）。

## 五、与诊断卡的关系

`composition_mode` 的选择应主要依据 `00-source-diagnosis-card.md` 里
的构图相关字段（俯瞰角度、重复单元、主体轮廓强度等），而不是单纯看
题材名字——比如"都市"题材，白天可能更适合 `urban_ink_volume`，夜景
可能更适合 `urban_grid_variation`；若诊断卡标注了高角度/俯瞰/重复
面群特征，则无论选中哪个 `composition_mode`，都应额外检查是否要
叠加激活 `flat_spatial_composition_route`。
